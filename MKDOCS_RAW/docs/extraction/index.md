## Extraction process

COCONUT provides the data as PSQL dump.

Using a self created vocabulary, we set up several rules to transform the data into RDF data.
For the transformation we used [eccenca corporate memory](https://eccenca.com/products/enterprise-knowledge-graph-platform-corporate-memory)

The vocabulary can be found at [https://coconutkg.aksw.org/ontology/index.html](https://coconutkg.aksw.org/ontology/index.html)
